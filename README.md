## `~/principles`

| Principle | Engineering Focus |
|---|---|
| **Clean Architecture** | Strict boundaries and maintainable systems. |
| **Developer Experience** | Simple setup, clear documentation and sensible defaults. |
| **Performance** | Lean bundles, fast infrastructure and optimized delivery. |
| **Zero-Trust Security** | Validation, least privilege and secure development. |
| **Scalability** | Systems designed to grow from prototype to production. |
| **Privacy by Design** | Collect less. Protect more. Respect users. |
| **Open Standards** | Portable formats, APIs and minimal lock-in. |

## `~/development`

### Getting Started

